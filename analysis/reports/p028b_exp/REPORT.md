# LBS-P028B-EXP threat-aware run-color experiment

Generated by Godot `4.7.2-stable (official)` in 78.87 seconds. This is a **simulation-only** paired experiment; the playable generator and every production balance setting remain unchanged.

## Executive result

No arm is ready to ship. Moderate is the best candidate for a later human A/B: across all four colors it reduced paired mean threatened-starvation by 1.52s with `basic_matcher` and 1.12s with the weaker delayed policy, and all 12 playing seeds still won. However delayed YELLOW worsened by 0.74s, so even moderate does not pass the fairness gate cleanly. Mild improved totals by 0.53s / 0.74s but harmed delayed YELLOW by 1.02s; strong improved totals by 0.76s / 1.31s but harmed basic RED by 0.94s and offered no clear tradeoff advantage over moderate. The synthetic sweep proves progressively stronger urgency response with identical paired run lengths and no bag/repeat violations, but real outcomes show that selecting an urgent run is not equivalent to delivering a usable match in time.

## Reproduction and design

```bash
./scripts/analyze_threat_bias.sh --seeds 500 --scenario-seeds 12 --seed-start 29001 --duration 90.0 --step 0.100 --output analysis/reports/p028b_exp
```

The synthetic manipulation sweep uses 500 paired seeds, 300 emitted balls per seed, five threat schedules and all four arms. The real-model study uses 144 scenarios: 36 paired seed/policy cases per arm, each capped at 90.0 simulated seconds. `basic_matcher` is the P028AR fixed-X bot; `delayed_matcher` uses the same legal actions but can decide only every 1.2 seconds; `observe_only` is a no-shot pressure sanity check.

At each new run only, urgency is `clamp((15 - live time-to-defender) / 12, 0, 1)`. Remaining legal bag colors receive weight `1 + boost × urgency`: baseline 0, mild 0.5, moderate 1.5, strong 3.0. A no-threat moment returns the exact old bag candidate without consuming bias RNG. The current Battlefield snapshot is taken before chain advance, so run creation sees no future state and at most one outer step (0.100s) of lag. Every complete bag still contains each color exactly once; run lengths, 102 px/s feed, magazine, enemy stats and combat are untouched.

## Interpretation and recommendation

- **Mild:** reject this setting; its all-color fairness regression exceeds moderate. Across delayed-policy colors, summed paired mean-starvation delta is -0.74s and the worst color delta is +1.02s.
- **Moderate:** collect more human data in a later A/B; do not ship. Across delayed-policy colors, summed paired mean-starvation delta is -1.12s and the worst color delta is +0.74s.
- **Strong:** reject; extra strength offers no clear advantage over moderate. Across delayed-policy colors, summed paired mean-starvation delta is -1.31s and the worst color delta is +0.74s.

## Measurement definitions and limitations

- **Threatened starvation** is time with a direct non-Healyzard enemy at ≤10 seconds estimated contact while pair + loaded/next ammo + ready timing are not all present. Pair presence remains a launch proxy, never a guaranteed hit or match.
- Run-to-visible follows the first fresh ball UID from that selected run. Run-to-pair requires that same ball to join a visible adjacent same-color pair. Run-to-match is the first subsequent real match of that color, so overlapping runs can share a later match and causality is associative rather than exclusive. Unresolved events are retained in JSON scenario state but do not receive invented delays.
- The adaptive choice observes only current live enemy positions/states. Healyzards are excluded from direct breach time; their real healing still affects combat. Snake stun/transfer is included by `lane_time_to_danger`.
- The delayed bot's 1.2s cadence is deliberately weaker but invented, not human-calibrated. Both bots still see exact geometry instantly and lack touch error, perception delay, occlusion, planning and human emergency strategy. Win rate therefore cannot establish player difficulty or fun.
- Bag reordering cannot help when the urgent color was already consumed, and a selected run enters offscreen right before it can affect play. Bounded seeds describe this encounter and these policies, not population tails or phone usability.
